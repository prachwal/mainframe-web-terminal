## Phase 1: SCSS Token Foundation — Colors, Spacing, Typography

**Objective**: Establish the primitive palette, semantic color tokens (light + dark), spacing scale, and typography tokens.

**Deliverables** (3 files):
- `src/styles/tokens/_colors.scss` — primitive palette (slate/gray/blue/red/green/amber), semantic tokens (`$color-primary`, `$color-text-primary`, `$color-surface`, etc.), dark mode via `[data-theme="dark"]` block
- `src/styles/tokens/_spacing.scss` — 4px base scale (xs: 4px → 3xl: 48px), border-radius tokens, z-index tokens
- `src/styles/tokens/_typography.scss` — font stacks (mono + sans), sizes (xs→5xl), weights (300→800), line-heights

**Dependencies**: None

**Verification**: `pnpm lint` passes (no TS/JS files to lint yet — ESLint skips `.scss`; markdownlint only targets `src/**/*.md`)

## Phase 2: SCSS Token Foundation — Breakpoints, Shadows, Barrel

**Objective**: Complete token set with responsive breakpoints, elevation shadows, and a barrel re-export.

**Deliverables** (3 files):

- `src/styles/tokens/_shadows.scss` — elevation levels: `$shadow-sm`, `$shadow-md`, `$shadow-lg`, `$shadow-xl`; dark mode variants
- `src/styles/tokens/_index.scss` — barrel: `@forward` all 5 token partials

**Dependencies**: Phase 1
