# Branch, Commit, Merge

Create a new branch for the current working changes, commit them with a conventional commit message, and merge the branch back into `main`.

## Workflow

1. Check the current git status and identify the active branch.
2. Create a feature branch from the current state.
3. Review the staged changes and commit them with a conventional commit message.
4. Merge the feature branch back into `main`.
5. Confirm the repository is clean after the merge.

## Notes

- Preserve all existing user changes.
- Do not use destructive git commands.
- Prefer a branch name that reflects the current task.
