# NotFoundPage

## Tier
Page

## Description
Fallback view for unmatched routes.

## Route
`*`

## Dependencies
- PageShell (`templates`)
- Heading (`atoms`)
- Text (`atoms`)

## Usage Example
```tsx
import { NotFoundPage } from '@/components/pages/NotFoundPage';

<NotFoundPage />
```

## Accessibility
- Gives a clear recovery path instead of a blank screen.
