Master index of all UI components in the project, organized by Atomic Design tier.

## Registry Conventions

- Check this registry **before** creating any new component.
- Every component has a `<ComponentName>.md` spec file in its tier.
- Spec files must contain: Tier, Description, Props, Dependencies, Usage Example, Accessibility, Styling, Testing.
